# v1.0.0 migration note

This release sets a stable baseline for the ForEveryone design system.

## What changed

- Credits now show named design-system contributors with role context.
- Accessibility guidance for editors is clearer and easier to apply.
- Shared motion behavior now respects reduced-motion preferences.
- Button documentation now matches current prototype behavior.

## What editors should do

- Use the updated accessibility guidance when preparing new pages.
- Keep image alt text meaningful and specific to each image.
- Verify interactions still feel clear when reduced motion is enabled.

## What implementers should do

- Pull `v1.0.0` or later for the baseline release state.
- Keep root and prototype versions aligned in future releases.
- Continue writing changelog entries for non-developer stakeholders.
